## 关于附件的说明

演示数据中的 11 个附件（PDF / PNG / DOCX / XLSX / Markdown）**不是预先打包的二进制资源，而是
后端首次启动时用 PDFBox、Apache POI 与 Java2D 现场生成的**，内容与知识条目一一对应。
这样做有两个好处：

1. 仓库保持轻量，不需要提交二进制文件；
2. 附件正文可被真实检索到 —— 例如「信噪比衰减」这个词只出现在一个 Markdown 附件里，
   搜索它却能命中对应的知识条目，直接证明了"附件正文已进入索引"。

音视频样本未随附：生成合法的 MP4/H.264 需要编码器。上传链路对音视频完全支持
（见 `application.yml` 的 `kms.storage.allowed-extensions`），演示时可现场上传验证。
